# 🏦 MiniBank — Full Stack Banking Web Application

MiniBank is a full-stack banking web application developed using **Python**, **Flask**, and **PostgreSQL**.  
This project was created by me and my friend @Azzeke as a university group project.

The application simulates core banking operations such as account management, transactions, money transfers, and user authentication in a modern web interface.

# ⚙️ Installation

## 📌 Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/minibank.git
cd minibank
```

---

## 📌 Create Virtual Environment

### Windows

```bash
python -m venv venv
venv\Scripts\activate
```

### Mac/Linux

```bash
python3 -m venv venv
source venv/bin/activate
```

---

## 📌 Install Dependencies

```bash
pip install -r requirements.txt
```

---

## 📌 Configure PostgreSQL

Create a PostgreSQL database and update your database credentials inside the project configuration.

Example:

```python
DB_NAME = "minibank"
DB_USER = "postgres"
DB_PASSWORD = "your_password"
```

---

## 📌 Run Application

```bash
python app.py
```
